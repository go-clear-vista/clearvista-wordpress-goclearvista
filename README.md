# clearvista-wordpress-goclearvista

Website update repo for goclearvista.com (WordPress, Divi).

- `CLAUDE.md`: site conventions, style reference, content rules and workflow
- `company-pages/`: generator, builds and previews for the Our Team, Certifications, Product Line Card and Careers redesign drafts
- `service-pages/`: generator, built layouts, tools and previews for the redesigned service pages
- `notes/`, `scripts/`: specs, code, SEO text, footer code and tools for the solution pages
- `page-backups/`: page content before and after each live change
- `docs/`: competitor research and logs of live-site changes
